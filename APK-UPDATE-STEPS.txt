UMES VR CLASSROOM — UPDATE THE APK WHEN THE TEMPORARY TUNNEL URL CHANGES

Project folder:
/Users/tinaatia/Desktop/Sager-VR

Use these steps when a restarted temporary tunnel gives you a new HTTPS address.
Changing Wi-Fi does not require a rebuild if the same tunnel keeps its address.

1. START THE APP SERVER

If the server is already running on port 3100, leave it running.
Otherwise, open Terminal and run:

cd /Users/tinaatia/Desktop/Sager-VR
SERVE_WEB_APP=true PORT=3100 npm run dev:server

Leave this Terminal open. If port 3100 is already in use, do not start a duplicate.

2. START THE TEMPORARY TUNNEL

Open another Terminal tab and run:

cd /Users/tinaatia/Desktop/Sager-VR
apk/tooling/bin/cloudflared tunnel --no-autoupdate --protocol http2 --url http://127.0.0.1:3100

Copy the HTTPS address printed by Cloudflare, such as:
https://some-new-address.trycloudflare.com

Leave this Terminal open. Use the address from YOUR Terminal, not the example.
If your existing tunnel still works, you can keep it instead of starting another.

3. UPDATE, REBUILD AND SIGN THE APK

Open a third Terminal tab. Replace NEW-ADDRESS below with the actual tunnel address:

cd /Users/tinaatia/Desktop/Sager-VR
node apk/rebuild-test-apk.cjs https://NEW-ADDRESS.trycloudflare.com

The helper will:
- Check that the new address serves the app manifest.
- Update the APK launch address.
- Increase the Android version number.
- Keep the same package name and signing key.
- Build the website and Android APK.
- Verify the APK signature and certificate configuration.
- Print a versioned Device Manager download URL.

The latest APK is saved at:
/Users/tinaatia/Desktop/Sager-VR/apk/UMES-VR-Classroom-test.apk

A versioned copy is also saved in apk/, for example:
UMES-VR-Classroom-test-v2.apk

Wait for the update to finish successfully. If it reports an error, resolve it
before deploying; an older APK may still be present at the latest-file path.

4. INSTALL OR UPDATE THROUGH META DEVICE MANAGER

- Open Device Manager > Apps & content > Manage apps.
- If UMES VR Classroom is not listed, add it using the private/self-hosted app option.
- If it is already listed, open its app configuration/update options.
- Use the NEW versioned download URL printed by the rebuild helper.
- Deploy/assign the app update to the intended headsets or device group.
- Wait for installation, then launch the updated app on a Quest.

For self-hosted updates, changing the APK file at an old URL does not automatically
update the installed app. Provide the new versioned URL to Device Manager.

Meta guide:
https://developers.meta.com/vr/resources/qfb-private-apps-dist/

IMPORTANT FILES AND RUNNING SERVICES

Keep these private signing files and back them up:
apk/signing/umes-vr-test.keystore
apk/signing/test-signing.json

Do not delete or share them. Updates require the same signing identity.
Keep the package name unchanged: edu.umes.vrclassroom.test

Keep the computer awake and connected to the internet. Keep both the app server
and the tunnel running while the headsets use this test APK.

A new temporary tunnel address requires rebuilding and reinstalling the APK.
A permanent domain with a named tunnel avoids URL-related rebuilds.
